# Project Overview

## Purpose

The **AI Trip Planner** is an intelligent travel itinerary generator that leverages artificial intelligence to create personalized trip plans. Users can specify their destination, travel duration, budget preferences, and traveling party size, and the application generates a complete itinerary with hotel recommendations and daily activity plans.

## Main Functionality

### Core Features

1. **AI-Powered Trip Generation**
   - Uses Google Gemini 2.5 Flash AI model to generate intelligent trip itineraries
   - Provides customized recommendations based on user preferences
   - Generates hotel options and day-by-day activity plans

2. **User Authentication**
   - Google OAuth 2.0 integration for secure sign-in
   - Persistent user sessions via localStorage
   - User-specific trip history and management

3. **Trip Customization**
   - Destination selection with Google Places autocomplete
   - Trip duration (1-5 days)
   - Budget tiers: Cheap, Moderate, Luxury
   - Traveler types: Solo, Couple, Family, Friends

4. **Trip Management**
   - Save generated trips to Firebase Firestore
   - View all personal trips in a dashboard
   - Access detailed trip information with maps and photos

5. **Rich Media Integration**
   - Google Places API for location photos
   - Interactive Google Maps links for hotels and attractions
   - Responsive image loading for destinations

## Key Integrations

### 1. Google Gemini AI
- Model: `gemini-1.5-flash`
- Purpose: Generate trip itineraries based on user inputs
- Input: Structured prompt with location, days, budget, travelers
- Output: JSON with hotel options and daily activity plans

### 2. Google Places API
- Version: v1 (REST API)
- Purpose:
  - Location autocomplete in trip creation
  - Fetch photos for hotels and attractions
  - Search for place details
- Field Masks: photos, displayName, id

### 3. Firebase Firestore
- Collection: `AiTrips`
- Document Structure:
  - User email
  - User selections (location, days, budget, travelers)
  - Generated trip data (hotels, itinerary)
  - Timestamps

### 4. Google OAuth 2.0
- Provider: `@react-oauth/google`
- Flow: Authorization code flow
- Scope: User profile information (email, name, picture)
- Storage: User data stored in localStorage

## Deployment

- **Platform**: Vercel (vercel.json configuration included)
- **Build Output**: Static files generated by Vite
- **Environment Variables**: Required for API keys (Google Places, Gemini AI, OAuth Client ID)

## Application Architecture

The application follows a **component-based architecture** with:

- **Feature-based folder structure**: Each major feature in its own directory
- **Service layer**: Separate modules for external API integrations
- **Shared UI components**: Reusable component library (Shadcn/ui)
- **Client-side routing**: React Router for navigation
- **State management**: React hooks + localStorage + Firestore

## Target Users

- Travel enthusiasts looking for AI-assisted trip planning
- Users who want quick, personalized itinerary suggestions
- Travelers seeking budget-conscious or luxury trip recommendations
- Anyone planning trips for various group sizes (solo to friends)

## Value Proposition

Instead of manually researching destinations, hotels, and activities, users can generate complete trip plans in seconds by simply providing basic preferences. The AI considers budget, travel style, and destination to create cohesive, practical itineraries.
